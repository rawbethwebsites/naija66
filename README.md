# Naija 66

Nigeria's 66th Independence Day celebration game. Play mini-games powered by real Nigerian achievements.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- **Frontend:** Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend:** Convex (real-time database, server functions)
- **Games:** Canvas/WebGL via Pixi.js/Phaser (Phase 2)
- **Animations:** Framer Motion

## Project Structure

```
src/
├── app/          # Next.js app router pages
├── components/   # React components
├── data/         # Game data, questions, state info
├── lib/          # Utilities and game state
└── styles/       # Global styles
```
